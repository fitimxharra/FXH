GITHUB DEPLOYMENT
1. Unzip archive locally.
2. Upload/replace each file into fitimxharra/FXH main branch, preserving assets/ folder.
3. Commit changes and wait for GitHub Pages deployment to complete.
4. Open https://app.fitimxharra.com and refresh. Existing locally stored photos should remain intact.

DO NOT clear site storage to refresh: it deletes locally stored photos and preferences.

NOTE: Web browsers may still allow manual 'Add to Home Screen' via their own menus;
the app no longer advertises installation in its interface.
